# Portfolio Showcase

Repository ini adalah versi showcase untuk kebutuhan portfolio dan rekrutmen.
Source code aplikasi, konfigurasi deployment, credential, seed data, backup
operasional, detail endpoint, serta skema database sengaja tidak disertakan.

Fokus showcase ini adalah konteks masalah UMKM, proses pengembangan, kontribusi
tim, kemampuan teknis, fitur utama, arsitektur tingkat tinggi, hasil pengujian,
dan tampilan aplikasi.
